# Chicken Merge - GitHub Pages

这是 Chicken Merge 游戏的官方网站，用于 Google Play 商店上架认证。

## 网站内容

- **首页 (index.html)**: 展示游戏介绍、截图和特色功能
- **隐私政策 (privacy-policy.html)**: 完整的隐私政策文档，符合 Google Play 要求
- **样式文件 (style.css)**: 响应式设计，支持移动端和桌面端

## 游戏截图

网站展示了4张游戏截图：
- splash.png - 游戏启动画面
